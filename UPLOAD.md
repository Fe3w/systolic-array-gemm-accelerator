# How to upload (so no image is missing)

The folder `sysarray-upload/` mirrors the repo. Every file in it is needed:
the README shows images from docs/img/ and results/perf/, and links to the docs pages.

On github.com (repo page → Add file → Upload files):
1. Open `sysarray-upload/` on your computer.
2. Select everything INSIDE it (README.md, docs, results, scripts) and drag it
   onto the upload page. GitHub keeps the folder paths.
3. Commit. Existing files with the same path are replaced.

Or with git:  cp -r sysarray-upload/* <your clone>/ && git add -A && git commit
